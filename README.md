## 我的櫃子

記錄家裡每個櫃子、每一格放了什麼東西，可以跟家人共用。

- 網址：https://mei0829.github.io/Mei-Good-Life/cabinet.html
- 跟記帳用同一個帳號登入，但資料**不跟記帳放在一起**：存在「家庭空間」`families/{id}/data/cabinet`，成員都能看、能改，家人改了會即時更新。
- 在「⋯ 設定 → 家人共用」用 Email 邀請家人。管理員邀請時會順便把對方加進網站的邀請名單。
- 按住東西拖到別格就能換位置（手機要先按住一下再拖）；按住格子的名稱拖到別格，兩格會整格交換。每次變更都可以按「復原」。
- 可以搜尋東西在哪、分地點（書房、客廳…）、自訂每個櫃子的層數和每層格數、下載備份檔。
- 格子可以自訂形狀：點格子切成「幾層 × 幾格」，切出來的也能合併回去。
- 保固：每樣東西可以記購買日期和保固到期日。「保固」裡有月曆和快到期清單，30 天內到期會在上方提醒。

### 第一次使用前：開通家庭空間

到 Firebase 主控台 → Firestore Database → 規則，把 `firestore.rules` 的內容整份貼上取代原本的規則（原本的規則都已包含在裡面），按「發布」。

## 旅遊行程

規劃自己的每一趟旅行，跟記帳連在一起。

- 網址：https://mei0829.github.io/Mei-Good-Life/trip.html （只有管理員能打開，跟記帳一樣）
- **只有自己看得到**：資料存在自己的私人資料 `data/users/{uid}/trip`，手機和電腦會同步。最早的版本存在家庭空間，打開時會自動搬回私人資料，家庭空間那份清空。
- 旅行列表分成「旅行中／即將出發（倒數幾天）／還在想／去過的地方」。
- **行程**：填出發、回程日後自動分成每一天，每個行程有類型（景點、美食、交通、住宿、購物、其他）、時間、地點（點了打開 Google 地圖）、預估花費、備註。同一天照時間排。旅行中會標出「今天」。還沒決定哪天去的放在「口袋名單」。改出發日時，排好的行程會跟著移動。
- **準備清單**：旅行列表上方有「行李清單公定版」，在那裡統一新增、改名、刪除、排順序。新的旅行會先複製一份公定版，之後各自獨立：在旅行裡勾選、新增、改名、刪除都不會影響公定版和其他旅行；公定版改了也不會改到已經建立的旅行。旅行裡可以按「從公定版補上缺少的」（改過名的項目不會重複補）或「把這份存成公定版」。
- **跟記帳連動**（帳只記在記帳，不會重複）：
  - 每趟有日期的旅行，在「記帳 → 更多 → 旅行」會自動有一筆同名、同日期、同預算的旅行（`plan` 欄位對到行程的 id），名稱、日期、預算以行程頁為準。記帳那邊的旅行明細有「看這趟的行程」連回來。
  - 行程頁右上角「💰 記帳」、或點某個行程按「付錢了，記到記帳」，會打開記帳的新增畫面，日期、金額、名稱、分類（美食→餐飲、交通→交通、購物→購物、景點→娛樂）都先填好，儲存後自動回到行程。
  - 「花費」分頁顯示**實際花了多少**（從記帳讀出來，算法跟記帳的旅行一樣）、跟預算比、實際花在哪些分類，還有行程的預估花費。
- 「⋯」可以編輯旅行、複製成文字（貼到 LINE）、複製一份當範本、刪除；每次變更都可以按「復原」。設定裡可以下載備份檔。

## 作業與成績

老師用的作業繳交、成績、訂正追蹤，手機和電腦都能用，可以管好幾個班級，也可以跟協同老師一起管理。

- 網址：https://mei0829.github.io/Mei-Good-Life/school.html （獨立的頁面，網站首頁沒有放卡片，直接打開這個網址；可以「加到主畫面」當 App 用，沒網路也能打開）
- 資料存在共用空間（空間標記 `kind: 'school'`）：班級、學生、科目、作業種類在 `families/{id}/data/school`，每個班級的作業各存一份 `families/{id}/data/school_c_{班級id}`（一份文件最多 1 MB，大約可以存一個班一年以上；設定裡可以整理舊作業）。在「⋯ 設定 → 一起管理」用 Email 邀請，對方改了會即時更新。不用改 Firebase 規則。
- **首頁（班級管理中心）**：目前班級（點名稱切換）、學生人數、尚未繳交、尚未訂正，以及六個功能：學生個人檔案、每日繳交追蹤、各科作業管理、成績管理、訂正進度、成績匯出。第一次打開先建立班級、貼上學生名單（一行一位，可以加座號，可以從 Excel 直接貼上）。
- **出作業**：選科目 → 作業種類（國語習作、國語甲本、國語乙本、圈詞、生字簿、數學習作、數學練習簿、社會習作、社會練習簿、各科考卷…，可以在設定自己加）→ 範圍（第幾課、第幾頁）→ 繳交日。考卷預設「要打分數」。可以一次出給好幾個班。
- **學生個人檔案**：每個人有幾樣未交、待訂正；點進去看已完成／未繳交／待訂正、各科平均、作業紀錄表（日期、項目、繳交狀態、訂正狀態）和待處理事項，可以複製聯絡簿提醒。點任何一列可以改交的日期、分數、訂正哪裡、聯絡簿、免交。
- **每日繳交追蹤**：選一天，表格是「座號、姓名 × 這天要交的作業」，點「已交／未交」切換；可以只看尚未繳交、尚未訂正；點作業名稱可以「其他人都交了」或輸入分數。下面有「產生未交名單」「需要寫聯絡簿的學生」，以及之前還沒交的作業。
- **各科作業管理**：依科目列出每份作業的已交人數、未交、待訂正；點進去是全班名單（繳交、分數、訂正）。
- **成績管理**：選科目、日期範圍，看全班 × 每次考試的分數表和平均。**用計算機輸入分數**：一位一位按數字、按「確定」跳下一位，有 100／95／90… 快速鍵、缺考／免、上一位／下一位；電腦可以直接用鍵盤打數字、按 Enter。
- **訂正進度**：每份作業還沒訂正的學生和訂正哪裡，按「訂正好了」。
- **成績匯出**：選班級、科目、開始和結束日期，匯出成績或繳交與訂正紀錄（CSV，Excel 可開）。
- **我自己／上課中**：首頁最上面手動切換。
  - **我自己**：現在第幾節、下一節是什麼（幾分鐘後）、今天的備註（例如運動會、外出），還有今天要做的事、下一節前要準備的。
  - **上課中**：投影到電視的畫面（字很大、只顯示座號）：今天的作業（給學生抄聯絡簿）、記得帶、快要考試，以及「幾號什麼還沒交／還沒訂正」。老師點項目可以直接標成交了、訂正好了。可以全螢幕、換班級。
- **聯絡簿**：每班每天一份。這天出的作業會自動列進去（可以不顯示），也可以自己加；「記得帶」可以寫全班或某個座號；沒交的自動列出座號。可以投影或複製成文字。存在班級的共用資料裡。
- **課表**：每週課表（點格子選班級、科目，或寫導師時間等），上下課時間可以改；調課、帶學生外出到「某一天調課／外出」只改那一天。**只有自己看得到**，存在自己的私人資料 `data/users/{uid}/sch_pv`。
- **我的待辦**：某一天、每週重複、沒有日期；可以指定幾點或「某一節課前」，設定提醒（時間到、10／30 分鐘前、1 小時前、前一天）。**只有自己看得到**（跟課表存在一起）。提醒：頁面開著時會跳通知；要關掉頁面也會響，按「📅 加到手機行事曆」，由手機的行事曆提醒（.ics 檔）。
- **學習扶助**：班級可以標記成「學習扶助」（例如「學扶國語」「學扶英語」），一樣可以記作業、成績、放進課表。課表的「上下課時間／加時段」可以加「課後」等時段。
- **班費與經費**：每個班級一本帳。記收入、支出（分類：文具、獎品、點心、影印、教材、活動…）；學習扶助可以設預算，看已經花了多少、還剩多少；「收班費／費用」可以設每人多少錢，一個一個勾誰繳了，收到的錢自動算進收入；「花在哪裡」看各分類花了多少；可以下載帳本（CSV）。存在班級的共用資料裡。
- **【我自己】首頁**：最上面是「📌 待辦事項」（字最大，含考試的出題、影印提醒），接著「✏️ 今天要批改」（每個班今天要交的：早自修、前一天聯絡簿上的作業，顯示已登記幾位）、「⚠️ 未繳交紀錄」、接下來的考試；班級和功能按鈕縮小放在最下面。
- **早自修 → 批改項目**：在聯絡簿的「🌅 早自修」輸入「成語一、成語二」，每一項都會變成**當天**要批改的作業；「📒 今天的作業」輸入「數學習作 p.30–31」，會變成**下一個上課日**要批改的作業（週五 → 下週一）。輸入時先點科目、再點項目（國語習作、甲本、圈詞…，可以「＋ 新項目」自己加，例如成語），再填頁數或課次；會記住上次選的。也可以直接打字，會自動猜科目（成語、圈詞 → 國語…）。也會一起投影在黑板上。
- **考試**：記期中考、期末考的日期、範圍；「我要出題」的出題截止預設考前三週（前一週開始出現在待辦），「確認考卷影印」預設考前三天。可以加到手機行事曆。只有自己看得到。
- **沒帶紀錄**：每日繳交追蹤上面有「📒 聯絡簿檢查」，點一下就是沒帶；也可以記沒帶作業簿、課本、水壺…。作業沒交、遲交（晚幾天補交）會從作業紀錄自動算，補交了紀錄也會留著。「沒帶紀錄」頁看全班統計，點學生看他這學期每一天的紀錄。
- 設定裡可以管理班級、學生（座號、名字）、科目、作業種類、備份檔；每次變更都可以按「復原」。

## 東京餅創業

泰式東京餅（麵糊餅皮）的創業資料庫，可以跟創業夥伴共用。

- 網址：https://mei0829.github.io/Mei-Good-Life/biz.html
- **原物料**：每次買材料記一筆價格（日期、總價、數量、店家），自動算單價（g、ml 每 100 計），看得到漲跌。數量可以用 kg、台斤、L 輸入。
- **新點子**：記下想法，標記「想法／測試中／採用／放棄」，夥伴可以在下面留言討論。
- **口味筆記**：每個口味的材料和用量、做法、好吃程度、試做筆記。填上「一批做幾片」和售價，會用原物料最新價格算出每片成本和毛利。「麵糊」也是一種口味，其他口味可以直接加入麵糊（用量填片數）。
- 資料存在**創業空間**（`families/{id}/data/biz`，空間標記 `kind: 'biz'`），跟「我的櫃子」的家人分開：家人看不到創業資料，夥伴也看不到櫃子。
- 管理員第一次打開會自動建立創業空間；在「⋯ 設定 → 夥伴共用」用 Email 邀請夥伴（會順便加進網站的邀請名單）。被邀請的人登入後，首頁就會出現「東京餅創業」卡片。
- 設定裡可以下載原物料價格表（CSV，Excel 可開）和備份檔。
- 不用改 Firebase 規則，`firestore.rules` 原本的家庭空間規則就適用。

## 幸孕女子（備孕與孕期健康日誌）

https://mei0829.github.io/Mei-Good-Life/blooming/

高質感的個人備孕、孕期健康管理網頁 App（女性生活雜誌、植物編輯風格），原名 Blooming Days，品牌名稱用活潑的手寫字 Yusei Magic，每個字微微歪斜。原本的「備孕懷孕」（`baby.html`）已經合併進來：網站首頁只剩「幸孕女子」一張卡片，打開舊的 `baby.html` 會自動換到這裡；舊版存在雲端的資料沒有刪除。原始碼在 `blooming/`，用 React + TypeScript + Vite + Tailwind CSS，部署時 GitHub Actions 會自動測試和編譯。

- **資料同步到自己的私人雲端**：先存在手機的資料庫（IndexedDB / Dexie），打開快、沒網路也能記；有登入就同步到 Firebase 的 `data/users/{uid}/`（跟記帳同一個地方，只有自己看得到），換手機不會不見，手機和電腦也會同步。登入跟網站其他頁共用，在記帳登入過就會自動登入；沒登入的話可以在「設定與備份 › 雲端同步」登入。
  - 雲端文件：`b_{資料種類}`（太大會分成 `.2`、`.3`…）、`b__settings` 設定、`b__meta` 刪除紀錄、`p_bd_{id}` 照片與附件（照片超過約 1 MB 會縮小後再上傳，手機上的原檔不變；不是照片又太大的只留在手機，設定頁會提醒）。
  - 合併規則（`blooming/src/data/sync.ts`）：每筆紀錄比修改時間，新的贏；刪除會留下紀錄（400 天），別台裝置同步後也會刪掉；每天只能一筆的資料（身體、睡眠、日記）兩台裝置同一天各記一筆，留比較新的。
  - 什麼時候同步：改了資料 1.5 秒後、回到 App、連上網路、每兩分鐘。別台裝置加的照片，要看的時候才下載。
  - 預設的嬰兒用品、福利清單會等第一次同步完才決定要不要放，兩台裝置不會各放一份。
  - 「刪除全部資料」會連雲端一起刪。完整備份檔照樣可以下載。
- 八個模組：首頁、月經週期（日曆、基礎體溫、預測）、健康管理（身體、營養補充、睡眠、運動）、醫療管理（備孕檢查建議／產檢行事曆、看診紀錄、醫院醫師）、生活管理（運動與飲食建議、收藏、完成紀錄）、財務與保險（花費、預算、圖表、保險）、每日日記，以及寶寶準備（嬰兒用品清單、準媽媽福利清單，第一次打開會放好常見項目）。手機版把健康、醫療、生活合併成底部的「照護」，財務與保險、寶寶準備合併成「財務」。
- **介面全部使用台灣繁體中文**：品牌名稱也是中文；日期用「2026 年 11 月 6 日」、星期用「星期五」、金額用「元」。新增功能也要遵守。
- 每一頁都有一隻不同姿勢的柔和插畫風柯爾鴨（`blooming/src/components/Duck.tsx`）：首頁的鴨子跟著階段變化，其他頁在標題旁與空白提示上。
- **九個顏色主題**：森林綠、玫瑰奶茶、霧藍、鴨子奶黃，加上高質感的酒紅、琥珀金、靛藍、祖母綠，以及夜間，在「設定與備份 › 外觀」切換；也可以讓夜間模式跟著手機自動切換。顏色都在 `blooming/src/lib/theme.ts`，圖表也跟著主題換色。
- 階段：備孕中、懷孕中、產後（預留）。要自己確認懷孕並輸入末次月經，月經延遲不會自動切換；切換不會刪除任何資料。
- 週期預測只用自己的紀錄：少於兩次月經開始日不預測；資料少、週期不規律都會標示。
- 資料存取都在 `blooming/src/data/repo.ts`（Repository / Service Layer），之後要換成雲端只要另外實作 `DataService`。

開發：`cd blooming && npm install && npm run dev`；測試：`npm test`；編譯：`npm run build`。

## 行事曆

https://mei0829.github.io/Mei-Good-Life/cal.html （只有管理員能打開）

把幾個地方的日期放在同一個月曆上（只讀，點了會打開原本的網站修改）：

- 課表、跟進（下次跟進、產品跟進）、生日：讀新人名單（mei0829/Uultra）存在 `data/users/{uid}/s_events`、`s_people`、`s_side`、`s_leaders` 的資料
- 保固到期：讀「我的櫃子」家庭空間的資料
