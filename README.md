## 我的櫃子

記錄家裡每個櫃子、每一格放了什麼東西，可以跟家人共用。

- 網址：https://mei0829.github.io/Mei-Good-Life/cabinet.html
- 跟記帳用同一個帳號登入，但資料**不跟記帳放在一起**：存在「家庭空間」`families/{id}/data/cabinet`，成員都能看、能改，家人改了會即時更新。
- 在「⋯ 設定 → 家人共用」用 Email 邀請家人。管理員邀請時會順便把對方加進網站的邀請名單。
- 按住東西拖到別格就能換位置（手機要先按住一下再拖）；按住格子的名稱拖到別格，兩格會整格交換。每次變更都可以按「復原」。
- 可以搜尋東西在哪、分地點（書房、客廳…）、自訂每個櫃子的層數和每層格數、下載備份檔。
- 格子可以自訂形狀：點格子切成「幾層 × 幾格」，切出來的也能合併回去。
- 保固：每樣東西可以記購買日期和保固到期日。「保固」裡有月曆和快到期清單，30 天內到期會在上方提醒。

### 第一次使用前：開通家庭空間

到 Firebase 主控台 → Firestore Database → 規則，把 `firestore.rules` 的內容整份貼上取代原本的規則（原本的規則都已包含在裡面），按「發布」。

## 東京餅創業

泰式東京餅（麵糊餅皮）的創業資料庫，可以跟創業夥伴共用。

- 網址：https://mei0829.github.io/Mei-Good-Life/biz.html
- **原物料**：每次買材料記一筆價格（日期、總價、數量、店家），自動算單價（g、ml 每 100 計），看得到漲跌。數量可以用 kg、台斤、L 輸入。
- **新點子**：記下想法，標記「想法／測試中／採用／放棄」，夥伴可以在下面留言討論。
- **口味筆記**：每個口味的材料和用量、做法、好吃程度、試做筆記。填上「一批做幾片」和售價，會用原物料最新價格算出每片成本和毛利。「麵糊」也是一種口味，其他口味可以直接加入麵糊（用量填片數）。
- 資料存在**創業空間**（`families/{id}/data/biz`，空間標記 `kind: 'biz'`），跟「我的櫃子」的家人分開：家人看不到創業資料，夥伴也看不到櫃子。
- 管理員第一次打開會自動建立創業空間；在「⋯ 設定 → 夥伴共用」用 Email 邀請夥伴（會順便加進網站的邀請名單）。被邀請的人登入後，首頁就會出現「東京餅創業」卡片。
- 設定裡可以下載原物料價格表（CSV，Excel 可開）和備份檔。
- 不用改 Firebase 規則，`firestore.rules` 原本的家庭空間規則就適用。
